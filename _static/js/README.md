# Theme JavaScript

Each file progressively enhances a specific rendered feature: focused sections, overflowing navigation, page TOC state, search results, sidebar collapse, MathJax enhancement, MyOpenMath exports, heading matches, or lazy semantic reference previews. The preview core is deliberately DOM-free so URL-admission and shared-cache behavior can be tested without a browser; load it before the controller. The HTML/CSS baseline remains authoritative. Keep data attributes and class names synchronized with templates and extension output; verify math changes with `npm run test:math` and preview behavior with `npm run test:reference-previews`. See the parent [_theme README](../../README.md).
