# Theme CSS

`sphinx-theme.css` is the course-wide public theme override; `course-reference-preview.css` styles the one shared lazy semantic-preview card. Keep selectors synchronized with extension-emitted classes, preserve responsive and reduced-JavaScript behavior, and verify changed presentation in a local preview. `tippy.css` remains only for the documented legacy preview option. See the parent [_theme README](../../README.md) for builder placement and safety rules.
