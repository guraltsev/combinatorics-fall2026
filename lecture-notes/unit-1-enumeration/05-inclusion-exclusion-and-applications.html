      5. Inclusion–exclusion and applications#

      The sum rule applies directly to disjoint sets. When sets overlap, ordinary addition counts some objects more than once. The principle of inclusion–exclusion repairs this overcount systematically. More importantly, it gives a general strategy for restrictions: we begin with a convenient universe, describe each way an outcome can violate the restrictions, and count intersections of those violation sets.

      After studying these notes, you will be able to do the following.

      • Explain the correction terms in the two-set and three-set formulas.

      • State and justify the finite inclusion–exclusion formula.

      • Express a desired set as the complement of a union of violation sets.

      • Count bounded integer solutions by combining inclusion–exclusion with stars and bars.

      • Count strings and surjective functions that use every available symbol.

      • Apply block counting and inclusion–exclusion to forbidden substrings.

      • Derive the formula for derangements and count permutations with a specified number of fixed points.

      Inclusion–exclusion is not a substitute for modeling. The formula becomes useful only after we define the universe and violation sets and learn how we can count their intersections. The formula does not require pairwise disjointness; the alternating terms correct exactly that overlap.

      Warning 5.5.2 (Blocks can interact)#

      The gluing count above works cleanly because the three substrings use disjoint letters and have fixed internal order. If forbidden substrings overlap, share letters, or can occur more than once, an intersection may have several possible overlap patterns. Inclusion–exclusion still applies, but each intersection requires an accurate model before we insert it into the formula.

      5.7 Choosing useful violation sets#

      The four applications look different, but their solutions have the same structure.

      • For bounded solutions, violation is ; shifting variables and using stars and bars counts an intersection.

      • For all-symbol strings or surjections, violation is that symbol is missing; reducing the alphabet counts an intersection.

      • For forbidden substrings, violation is that a specified block occurs, and gluing all required blocks counts an intersection once we understand their interactions.

      • For derangements, violation is that position is fixed, and an fixing specified positions and permuting the rest counts an intersection.

      A productive violation set has two properties: the valid outcomes are precisely those with no violations, and intersections of specified violations are easier to count than the valid outcomes directly. If the intersections become harder than the original problem, a different universe or set of conditions may work better.

      4. Simultaneous violations. A -fold intersection imposes all conditions at once; it is not generally the product of the sizes of the individual violation sets.

      5. The number of intersections. If every -fold intersection has a common size, we multiply it by .
